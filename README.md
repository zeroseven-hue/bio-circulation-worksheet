# 國中生物 3-2 人體的循環 ✕《工作細胞》數位互動學習單

> 本專案為國中七年級生物「3-2 人體的循環」課堂素養數位學習單，結合日本動畫《工作細胞》第08話【血液循環】情境，專為智慧教室跑班與平板車教學設計。

## 🌟 核心特色
1. **100% 點選作答，零打字負擔**：全卷採用下拉選單與直覺點選，徹底排除學生手打錯別字與排版挫折。
2. **符合南一版 7 年級生物課綱**：無超綱內容，強化核心觀念與教師獨創通關口訣：**「靜房，心動出室」**。
3. **跑班平板車四重防護（`bio-curriculum-regular-workflow`）**：
   - 40 分鐘超時自動清空暫存。
   - 身分覆核門禁 Modal（防上一班誤交覆蓋）。
   - 投影派卷 QR Code 自動掛載 `?reset=1` 秒速開新卷。
   - 雙向成果卡與 8 秒 Wi-Fi 降級提交。
4. **內嵌 YouTube 教學影片**：支援時間軸秒速跳轉（01:20、05:40、08:30、10:15、13:30、16:30）。

## 🚀 學習單目錄
- `index.html`：智慧白板派卷與大螢幕 QR Code 投影大廳
- `3-2-circulation.html`：3-2 人體的循環 數位互動學習單主頁
- `circulation.js`：核心邏輯、平板車防呆守門與算分腳本
